# cv-site

Viktor Vasylyshyn's portfolio site. Built with Astro and Tailwind CSS.

## Commands

| Command           | What it does                              |
| ----------------- | ----------------------------------------- |
| `npm install`     | Install dependencies                      |
| `npm run dev`     | Start the local server at `localhost:4321` |
| `npm run build`   | Build the static site into `dist/`        |
| `npm run preview` | Preview the built site locally            |

A guide to editing the content (`src/content/`) will be added once the data files exist.
